# CliniGlow

Sistema completo de gestão para clínicas de estética.

## Funcionalidades

- Agenda com controle de conflitos
- Cadastro de clientes com histórico
- Procedimentos e sessões
- Antes e depois (fotos)
- Estoque com alerta de mínimo
- Financeiro (receitas e despesas)
- Relatórios e crescimento
- Pagamento via PIX (Mercado Pago)
- Painel administrativo

## Tecnologias

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Supabase (auth, database, edge functions)
- Recharts (gráficos)
- Vercel (deploy)
